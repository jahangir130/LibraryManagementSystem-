Library Management System - Packaged Java Project

Packages:
- library: LibraryItem, Book, Magazine, Loan, Member, Library
- app: Jahangir__20255103295 (main class)

Compile and run from the folder containing the library and app folders:
    javac -d out library/*.java app/*.java
    java -cp out app.Jahangir__20255103295

Note: Book ID and Magazine ID are unique to prevent findItem() ambiguity.
